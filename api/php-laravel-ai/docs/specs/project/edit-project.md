# Feature: Editar projeto

Endpoint para editar informações do projeto.

## Regras

- Title obrigatório.
- Description texto obrigatório.
- Receber ID do projeto pela url

## Saída esperada

```json
{
    "message": "Projeto atualizado com sucesso"
}
```

## Resultado esperado

- Registro atualizado no banco de dados.
